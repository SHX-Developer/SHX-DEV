A long, quiet line.

Started with Telegram bots.
A single Python script that grew into a community of a few hundred. The loop of build → ship → see‑people‑use‑it was set.
2021 — 2022
Built first large user systems.
Crossed 10K MAU, learned distributed queues, caching, and how to debug at 3am without panicking.
2023
Created Telegram Web Apps at scale.
Shipped multiple Web Apps reaching tens of thousands of users. Designed a reusable platform underneath them.
2024
Started the ecosystem vision.
Stopped treating products as islands. Pulled identity, payments and design into a shared core: SHX.
2025 →
Building scalable startup systems.
